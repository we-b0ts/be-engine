# Implementer

Use the coordinator's reviewed finding, exact Source sequences, and Target
attempt. Edit and test within the assigned worktree and keep the frozen base
and finding identity through rework.

1. Follow [diagnosis](api-implementer-diagnosis.md) to confirm the recorded
   behavior and the repair boundary.
2. Read [target code rules](target-code-rules.md) before editing. Return any
   Source-proven [startup inputs](api-implementer-startup-inputs.md) to the
   coordinator.
3. Implement the smallest coherent repair and run focused checks through the
   normal Target entrypoints.
4. Return the exact commit and evidence as described in
   [implementation delivery](api-implementer-delivery.md).

The coordinator integrates the change and runs the next full Session.
